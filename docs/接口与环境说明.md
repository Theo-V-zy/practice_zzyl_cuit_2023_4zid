# 接口与环境说明

## 后端接口

| 功能 | 地址 | 说明 |
| --- | --- | --- |
| 登录 | `POST /login` | 使用账号和密码登录 |
| 菜单 | `GET /sysMenus` | 加载左侧菜单 |
| 当前用户 | `GET /showInfo` | 查询登录用户信息 |
| 修改用户 | `POST /updateUser` | 修改个人信息 |
| 修改密码 | `POST /updatePwd` | 修改当前用户密码 |
| 文件上传 | `POST /upload` | 上传头像或护理项目图片 |
| 护理项目分页 | `POST /nursingItemPage` | 查询护理项目列表 |
| 新增护理项目 | `POST /saveNursingItme` | 老师代码接口名保留原拼写 |
| 修改护理项目 | `POST /updateNursingItme` | 老师代码接口名保留原拼写 |
| 删除护理项目 | `GET /deleteNursingItme?id=` | 按 id 删除 |
| 新增护理计划 | `POST /saveNursingPlain` | 保存护理计划和计划项目 |
| 护理计划分页 | `POST /pageList` | 查询护理计划列表 |

## 环境变量

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `BACKEND_PORT` | `8080` | 后端端口 |
| `MYSQL_URL` | `jdbc:mysql://localhost:3306/zzyl...` | MySQL 连接地址 |
| `MYSQL_USERNAME` | `root` | MySQL 用户名 |
| `MYSQL_PASSWORD` | `we005218` | MySQL 密码 |
| `VUE_APP_API_BASE_URL` | `http://localhost:8080` | 前端请求后端地址 |
| `VUE_APP_PORT` | `5173` | 前端开发端口 |
| `OSS_ACCESS_KEY_ID` | 空 | 阿里云 OSS AccessKey |
| `OSS_ACCESS_KEY_SECRET` | 空 | 阿里云 OSS Secret |
