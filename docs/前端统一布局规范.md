# 前端统一布局规范

## 公共布局

后台页面统一使用 `frontend/src/layouts/AdminLayout.vue`。公共布局严格按照原型组织为“顶部一级功能模块 + 左侧当前模块子菜单 + 右侧业务内容区”。`MainIndex.vue` 只负责承载公共布局和二级路由，组员不再复制顶栏、侧栏或用户下拉菜单。

页面内容通过路由插入公共内容区：

```vue
<template>
  <section class="page-section">
    <!-- 当前功能页面内容 -->
  </section>
</template>
```

页面组件只维护自己的查询条件、表格、表单和弹窗，不修改以下公共元素：

- 64px 顶栏、品牌 Logo、11 个一级功能模块和用户菜单
- 232px 左侧菜单、当前模块子菜单和菜单层级
- 页面内容区背景、边距和最小高度
- `App.vue` 的全局重置样式

## 路由约定

每个页面路由都要写 `meta.title`，顶栏面包屑会自动读取：

```js
{
  path: '/Visit',
  name: 'Visit',
  meta: { title: '来访管理' },
  component: () => import('@/views/Visit.vue')
}
```

菜单路径必须和路由 `path` 完全一致。新增菜单时，同时在 `database/zzyl.sql` 的 `t_menu` 和前端路由中登记，不能只改其中一处。

## 页面样式约定

- 使用 Element Plus 组件，按钮、表格、表单、分页和弹窗保持组件默认尺寸。
- 页面根节点使用 `.page-section`，不要重新设置 `body`、`#app` 或 `.admin-shell` 的尺寸。
- 颜色优先使用原型主色 `#0052d9`、文字色 `#333333`、辅助文字色 `rgba(0, 0, 0, 0.6)`、背景色 `#f4f5f7`。
- 表格和表单宽度使用 `width: 100%` 或父容器约束，不写超过内容区的固定宽度。
- 不在业务页面重复实现顶栏、侧栏、面包屑和退出登录。

## 开发检查

提交前至少检查：

```bash
npm run build
```

然后打开自己的页面，确认没有横向滚动条、顶栏没有被遮挡、刷新当前路由不会出现空白页。
