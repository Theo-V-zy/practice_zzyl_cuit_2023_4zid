# 组长负责模块功能拆分

当前分支：`feature/leader-base-auth`

原型依据：`后台原型图+prd`、`家属端原型图+prd`

## 负责范围

| 端 | 一级功能 | 原型页面 |
| --- | --- | --- |
| 管理端 | 登录 | `登录` |
| 管理端 | 工作台 | `工作台` |
| 管理端 | 个人中心 | `个人中心`、`修改密码` |
| 管理端 | 消息中心 | `消息通知` |
| 管理端 | 权限配置 | `用户信息`、`角色管理-菜单权限`、`角色管理-数据权限`、`菜单管理`、`部门管理`、`职位管理` |
| 家属端 | 登录 | `登录_1` |
| 家属端 | 我的 | `我的`、`我的合同`、`我的预约`、`我的订单`、`订单详情`、`我的账单` |

## 开发顺序建议

1. 公共基础：路由、布局、请求封装、登录态、菜单渲染。
2. 管理端登录、退出、个人中心、修改密码。
3. 管理端权限配置：用户、角色、菜单、部门、职位。
4. 管理端工作台和消息中心。
5. 家属端登录和“我的”相关页面。
6. 最后统一样式、菜单权限、数据权限和接口联调。

## 一、公共基础

### 目标

先搭好后台和家属端都能共用的基础能力，避免后面每个页面重复写登录判断、请求地址和菜单逻辑。

### 功能点

- 前端新增管理端布局：顶部栏、左侧菜单、面包屑、用户头像、退出按钮。
- 前端新增家属端布局：移动端尺寸、底部导航、顶部标题、返回按钮。
- 封装 `axios` 请求：统一 baseURL、超时、错误提示、未登录跳转。
- 登录态保存：后台用户和家属用户分开保存，避免互相覆盖。
- 路由守卫：未登录访问业务页时跳回对应登录页。
- 权限菜单：后台菜单按接口返回动态渲染。

### 建议文件

| 类型 | 建议位置 |
| --- | --- |
| 请求封装 | `frontend/src/api/request.js` |
| 管理端布局 | `frontend/src/layouts/AdminLayout.vue` |
| 家属端布局 | `frontend/src/layouts/FamilyLayout.vue` |
| 管理端页面 | `frontend/src/views/admin/` |
| 家属端页面 | `frontend/src/views/family/` |
| 路由配置 | `frontend/src/router/index.js` |

### 验收标准

- 后台登录后进入工作台，刷新页面不丢登录态。
- 家属端登录后进入“我的”，刷新页面不丢登录态。
- 退出登录后不能继续访问业务页。
- 菜单切换不会整页刷新。

## 二、管理端登录

### 原型页面

- `后台原型图+prd / 登录`

### 功能点

- 账号、密码输入。
- 登录按钮加载状态。
- 登录失败提示。
- 登录成功后进入工作台。
- 退出登录后清理登录态并回到登录页。
- 支持后续扩展验证码或记住密码。

### 后端建议

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/login` | `POST` | 当前老师代码已有登录接口，可先复用 |
| `/loadInfo` | `GET` | 当前登录用户简要信息 |
| `/logout` | `POST` | 退出登录 |

### 数据字段

- 账号：`account`
- 密码：`upwd`
- 登录用户：`id`、`realname`、`role`、`department`、`job`、`image`

### 验收标准

- 正确账号密码能登录。
- 错误账号或密码给出提示。
- 未登录不能访问工作台。
- 退出后再次访问工作台会回到登录页。

## 四、管理端个人中心

### 原型页面

- `后台原型图+prd / 个人中心`
- `后台原型图+prd / 修改密码`

### 功能点

- 查看个人资料：头像、姓名、手机号、邮箱、部门、职位、角色、性别。
- 修改可编辑字段：姓名、手机号、性别、头像。
- 上传头像。
- 修改密码：旧密码、新密码、确认密码。
- 表单校验：必填、手机号格式、两次新密码一致。

### 后端建议

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/showInfo` | `GET` | 老师代码已有个人信息接口 |
| `/updateUser` | `POST` | 老师代码已有修改个人信息接口 |
| `/updatePwd` | `POST` | 老师代码已有修改密码接口 |
| `/upload` | `POST` | 老师代码已有文件上传接口 |

### 验收标准

- 个人中心能正确回显当前登录用户。
- 修改后刷新仍能看到最新信息。
- 旧密码错误不能修改密码。
- 新密码和确认密码不一致时不能提交。

## 五、管理端消息中心
