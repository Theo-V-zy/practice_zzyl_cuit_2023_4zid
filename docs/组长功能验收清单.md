# 组长功能验收清单

分支：`feature/leader-base-auth` | 账号：`20260023` / `222222`

## 一、登录闭环

- [ ] 打开 `http://localhost:5173/`，看到登录页（蓝色渐变背景、"账号密码登录"标题）
- [ ] 输入错误密码 → 显示错误提示
- [ ] 输入正确账号密码 → 登录成功，跳转到工作台
- [ ] 右上角显示用户名和头像
- [ ] 刷新页面 → 不跳回登录页（登录态保持）
- [ ] 点击右上角 → 退出登录 → 确认弹窗 → 退出成功，跳回登录页
- [ ] 退出后直接访问 `http://localhost:5173/#/Dashboard` → 跳回登录页

## 二、布局导航

- [ ] 顶部 11 个一级模块：工作台/来访管理/入退管理/在住管理/服务管理/订单管理/财务管理/客户管理/权限管理/协同工作/智能监测
- [ ] 点击顶部模块 → 左侧子菜单切换
- [ ] 点击左侧菜单 → 右侧内容切换，不整页刷新
- [ ] 右上角消息铃铛图标 → 显示未读数量 → 点击跳转消息中心

## 三、工作台

- [ ] 我的信息卡片：显示"您好，xxx"、账号、角色、部门、职位
- [ ] 数据概览：老人数量/床位数量/员工数量/收入金额/服务单数量（带单位人/个/W元/w笔）
- [ ] 快捷方式：退款管理/待办事项/入账列表（点击跳转）
- [ ] 待办事项表格：显示申请编号和类型
- [ ] 预约总览表格：显示预约编号和来访人
- [ ] 老人统计：护理等级分布 + 年龄分布
- [ ] 数据统计：按月收入统计

## 四、个人中心

- [ ] `用户头像右上角 → 个人中心` 或左侧菜单进入
- [ ] 左侧表单：*姓名(可编辑)、*邮箱(只读)、性别、*所属部门(只读)、*所属职位(只读)、*角色(只读)、手机号(可编辑)
- [ ] 右侧头像：显示当前头像、上传按钮、"图片大小不超过2M"
- [ ] 点击保存 → 姓名和头像更新到右上角

## 五、修改密码

- [ ] 左侧菜单进入修改密码页
- [ ] 红*在原密码/新密码/确认新密码标签前方
- [ ] 密码框有眼睛图标可切换显示/隐藏
- [ ] 新密码长度8-20位，必须含数字+小写+大写字母
- [ ] 点击确定 → 校验通过 → 弹出"确认修改"弹窗："密码修改成功后需重新登录，是否继续？"
- [ ] 点击确定修改 → 修改成功 → 自动退出登录

## 六、消息中心

- [ ] 左侧菜单或铃铛进入
- [ ] 未读/已读 Tab（带数字）
- [ ] 消息类型筛选（系统通知/业务提醒/报警通知）
- [ ] 时间范围日期选择器
- [ ] 全部已读按钮
- [ ] 全部删除按钮（带确认）
- [ ] 点击消息标题 → 查看详情弹窗 → 自动标为已读
- [ ] 标记为已读按钮、删除按钮

## 七、权限配置-用户信息

- [ ] 左侧部门树 → 点击部门 → 右侧过滤该部门用户
- [ ] 查询：姓名(模糊)、用户状态(下拉)、邮箱(模糊)
- [ ] 新增用户：左侧选中部门后新增 → 弹窗填写姓名/角色/邮箱/职位/状态/性别/手机号
- [ ] 编辑用户、重置密码(确认弹窗："初始密码为888itcast.CN764%...")
- [ ] 启用/禁用（确认弹窗）
- [ ] 删除（仅禁用状态可删）

## 八、权限配置-角色管理
